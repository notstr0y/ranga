# RANGA

A community-driven academic resource platform for students studying under Kerala Technological University (KTU).

## About

RANGA aims to bring KTU academic resources together in one place.

### Planned features

- Previous Year Question Papers (PYQs)
- Academic notes and study materials
- Lab manuals and practical resources
- YouTube learning resources
- Global academic resource search
- Programme, scheme and semester-based browsing
- Progressive Web App (PWA) support

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Supabase
- PostgreSQL
- Cloudflare R2

## Development

```bash
npm install
npm run dev
```
